| Swift → Python stdin | crate path string written to the worker process |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-IPC | Tampering | shared worker stdout interleaving | mitigate | LibraryViewModel uses a DEDICATED PythonBridge; library commands never share the BatchViewModel pool (RESEARCH Pitfall 4) — interleaved JSON-Lines would mis-route results |
| T-04-STDOUT | Information Disclosure | accidental print() to stdout | mitigate | All LibraryViewModel diagnostics use fputs(..., stderr); stdout is reserved for Python JSON-Lines |
| T-04-NULLPATH | DoS | selectCrate on implied-parent (cratePath nil) | mitigate | guard cratePath != nil returns early; non-selectable nodes never issue list_tracks (Pitfall 1) |
</threat_model>
