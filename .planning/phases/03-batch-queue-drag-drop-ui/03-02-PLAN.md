<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| TrackDetailView → NSWorkspace | Backup file path from AnalysisResult.backupPath passed to activateFileViewerSelecting. Path originates from Python worker's JSON result; treated as a file system path. |
| BPM override popover | User-supplied integer values from Stepper; range is bounded by Stepper in: range, so no integer overflow risk. Values passed to PythonBridge.analyzeStream as bpmMin/bpmMax integers. |
| Cancel button → PythonBridge.terminate() | Actor-isolated method call. Terminates the Process. The terminationHandler fires and handleCrash() runs — existing Phase 2 crash-recovery logic. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-02-01 | Tampering | TrackDetailView — backup path passed to NSWorkspace | accept | Path originates from Python's JSON result (write-validated by Phase 1/2). NSWorkspace.activateFileViewerSelecting reveals in Finder — does not execute or open the file. No injection risk. |
| T-03-02-02 | Tampering | BPM override Stepper — integer range | mitigate | Stepper in: range enforces 20...299 for min and 21...300 for max. Values outside this range are structurally impossible from the UI. Python analyze.py validates bpm_min/bpm_max on its side (Phase 1 contract). |
| T-03-02-03 | Denial of Service | Cancel Analyzing row — repeated rapid cancel clicks | accept | Each cancel calls process.terminate() once. POSIX guarantees terminate() is idempotent; multiple SIGTERM to a terminated process is a no-op. The UI removes the X button when status transitions to .failed (terminal state). |
| T-03-02-04 | Information Disclosure | Failed row accordion — Python traceback in errorMessage | accept | Error messages are shown only to the local user (single-user desktop app). Python stderr diagnostics (tracebacks) go to stderr drain, not to errorMessage — only the JSON "msg" field surfaces. This is intentional for usability. No PII is present. |
| T-03-02-SC | Tampering | npm/pip/cargo installs | accept | No new external packages in Plan 03-02. All components are SwiftUI built-ins and AppKit. Package legitimacy gate not applicable. |
</threat_model>
